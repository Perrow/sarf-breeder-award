Tillbaka till import · Tillbaka till arter

Filformat

Importfilen är JSON och ska innehålla version: 1 samt en lista med arter i species.

Fullständig import av en ny art

{
  "version": 1,
  "species": [
    {
      "genus": "Aulonocara",
      "scientific_name": "stuartgranti",
      "breeding_class": "bronze",
      "swedish_names": ["Påfågelciklid"],
      "english_names": ["Flavescent peacock"],
      "scientific_synonyms": [],
      "geographies": ["Afrika", "Malawi"],
      "links": [
        {
          "url": "https://example.org/aulonocara-stuartgranti",
          "source_name": "Example",
          "title": "Aulonocara stuartgranti"
        }
      ]
    }
  ]
}

För en ny art krävs genus, scientific_name, breeding_class och minst ett värde i swedish_names. geographies är valfritt och kan innehålla flera geografier.

Kompletteringsimport av en befintlig art

För en art som redan finns räcker det att ange genus och scientific_name plus de uppgifter som ska läggas till.

{
  "version": 1,
  "species": [
    {
      "genus": "Aulonocara",
      "scientific_name": "stuartgranti",
      "geographies": ["Malawi"],
      "links": [
        {
          "url": "https://new.example.org/aulonocara-stuartgranti",
          "source_name": "New Example"
        }
      ]
    }
  ]
}

Hur importen fungerar

  • Importen är additiv. Utelämnade fält tar inte bort eller nollställer befintlig information.
  • Samma fil kan importeras flera gånger utan att skapa dubbletter av arter, synonymer, geografier eller länkar.
  • Matchning på genus och vetenskapligt artnamn är skiftlägesokänslig.
  • Geografier matchas också skiftlägesokänsligt. Befintlig stavning bevaras.
  • Angivna geografier läggs till på arten. Geografier som inte finns med i en kompletteringsfil tas inte bort.
  • Om aktuellt vetenskapligt namn inte hittas försöker importen matcha ett gammalt vetenskapligt namn som finns registrerat som synonym.
  • Om samma gamla vetenskapliga namn pekar på flera arter avbryts den raden med ett tydligt fel i stället för att välja godtyckligt.
  • Befintlig breeding_class skrivs inte över vid kompletteringsimport.
  • Om ett svenskt eller engelskt namn skiljer sig från det aktuella namnet kan det läggas till som synonym enligt importens befintliga regler.
  • Länkar identifieras per art och URL. Befintlig länk återanvänds och saknad titel eller källa kan kompletteras.

Fält

FältBeskrivning
genusVetenskapligt släktnamn. Alltid obligatoriskt.
scientific_nameVetenskapligt artnamn/artepitet. Alltid obligatoriskt.
breeding_classbronze, silver eller gold. Krävs när en ny art skapas.
swedish_namesLista med svenska populärnamn. Minst ett krävs när en ny art skapas.
english_namesValfri lista med engelska populärnamn.
scientific_synonymsValfri lista med tidigare eller alternativa vetenskapliga namn.
geographiesValfri lista med geografier, exempelvis ["Afrika", "Malawi"]. Flera geografier kan kopplas till samma art.
linksValfri lista med externa länkar. url krävs; source_name och title är valfria.
